# Pizza Order Bot 🍕

Бот для заказа пиццы прямо в Telegram с удобным интерфейсом и функциональностью администратора.

## Возможности

### Для пользователей:
- 🍕 Просмотр меню с фотографиями и описанием пицц
- 🛒 Добавление пицц в корзину
- 📦 Оформление заказа с указанием адреса, телефона и комментария
- 💳 Выбор способа оплаты (наличные, СБП, криптовалюта, банковская карта)
- 🏠 Указание адреса доставки
- 📱 Подтверждение заказа с получением номера заказа

### Для администраторов (перед этим добавьте ваш ID в поле ADMIN_IDS):
- /admin для вызова команд администратора 
- 👁️ Просмотр всех заказов
- ➕ Добавление новых пицц в меню (название, описание, фото)
- ➖ Удаление пицц из меню
- 📊 Просмотр статистики (количество пицц, заказов, пользователей)

## Установка и запуск

1. Убедитесь, что у вас установлен Python 3.9+
2. Установите зависимости:
```bash
pip install aiogram python-dotenv
```
3. Введите ваш токен бота в поле 
        bot = Bot(token="Ваш токен")

## Запуск бота 
- python main.py
